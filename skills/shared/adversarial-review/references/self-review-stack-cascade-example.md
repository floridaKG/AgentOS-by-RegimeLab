# Worked Example: Self-Administered Adversarial Review

## The Pattern

1. **Build the full case first** — extrapolate implications systematically using a layer-cake analysis (first-order -> second-order -> third-order effects).
2. **Switch to adversarial mode.** Apply the adversarial rubric to your own work. Assume your analysis is wrong and hunt for the strongest disconfirming evidence.
3. **Label each claim:**
   - **STRONG** — survived adversarial review, grounded in evidence
   - **WEAK** — narratively appealing but evidence doesn't hold
   - **OPEN** — plausible but unresolved, depends on unknown factors
4. **Deliver the refined thesis** — what survived, what didn't, and what the unresolved tensions are.

## What Survived vs What Failed

| Category | What typically survives | What typically fails |
|----------|----------------------|---------------------|
| STRONG | Claims grounded in observable trends, regulation, or hard constraints | |
| WEAK | | Narratively clean cascades where each link assumes the prior one holds ("everyone will do X because it's rational") |
| OPEN | Plausible scenarios where the key variable is a policy choice or unknown | |

## Key Lessons

1. The layer-cake framework is useful for structuring extrapolations but produces too-clean cascades. Always revisit.
2. Distinguish between *supply chain leverage* and *willingness to use it* — they are often inversely correlated.
3. Economic gravity (access to markets, capital, talent) is the strongest counterforce to sovereignty plays.
4. Treat "preposterous" from a reader as a signal that the cascade needs a self-review pass — label which parts failed and why.
5. A refined thesis that carries its own caveats is more defensible than an unfalsifiable extrapolation.
