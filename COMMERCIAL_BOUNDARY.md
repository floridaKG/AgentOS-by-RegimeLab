# Open-Core and Commercial Boundary

Agent OS is published under Apache 2.0: the full harness — local memory,
agent routing, provider-neutral orchestration, governance scaffolding, and
extension contracts — is free and open source.

## Open-Core (Apache 2.0)

- Local SQLite memory, recall, injection, and promotion contracts
- Optional Pinecone and Neo4j adapters
- ACP-compatible agent/provider routing
- MOE and multi-agent orchestration
- Generic Vault OS and SuperDocs scaffolds
- Public registries, health checks, and release gates

## Reserved for Managed or Commercial Products

- Hosted memory infrastructure, backups, migrations, and retention controls
- Managed provider credentials, billing, routing, and cost optimization
- Team administration, SSO, permissions, and compliance controls
- Hosted orchestration, observability, run analytics, and evaluation systems
- Premium adapters, curated domain skill packs, and proprietary workflows
- Personalized research, investment, venture, and intelligence skills

The public Vault OS example is intentionally structural. Personalized and
domain-specific Vault skills are not part of the open-source distribution.
