# Tool Map

Quick reference for tools and integrations available to agents working in this project.

## Agent OS Tools

| Tool | Purpose | Invocation |
|---|---|---|
| skill-rank | Rank skills by relevance | `skill-rank "<task>" --top 3` |
| skill-pack | Extract bounded context | `skill-pack <name> --budget 4000` |
| memory-st | Short-term memory | `memory-st write --intent LESSON --summary "..."` |
| recall | Cross-tier search | `recall "<query>"` |
