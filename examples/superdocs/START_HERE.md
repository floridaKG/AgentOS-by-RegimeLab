# START_HERE

Welcome to the SuperDocs documentation harness for your project.

## For Agents

Read in this order:

1. `governance/POLICY.md` — project rules and standards
2. `governance/decision-log.md` — architecture decisions
3. `guardrails/conventions.md` — coding conventions
4. `skills/SKILL_GLOSSARY.md` — available skills
5. `workflows/WORKFLOW_INDEX.md` — available workflows

## For Humans

This directory contains your project's documentation harness. Customize
the starter files to match your project's needs.

### Quick Customization

1. Edit `governance/POLICY.md` with your project rules
2. Add architecture decisions to `governance/decision-log.md`
3. Define coding conventions in `guardrails/conventions.md`
4. Add skills to `skills/` and index them
5. Define workflows in `workflows/` and index them

### Adding Content

- **Skills**: Create `.md` files in `skills/`, add entries to `SKILL_GLOSSARY.md`
- **Workflows**: Create `.md` files in `workflows/`, add entries to `WORKFLOW_INDEX.md`
- **Decisions**: Add ADR entries to `governance/decision-log.md`
- **Registry**: Add YAML files for structured metadata
