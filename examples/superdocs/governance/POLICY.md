# Project Policies: [Project Name]

## Code Standards
- All changes must be reviewed before merging to main
- Tests must pass before merge
- Documentation must be updated with feature changes
- Breaking changes require a deprecation notice

## Review Requirements
- Core modules: minimum 1 reviewer approval
- Infrastructure changes: minimum 2 reviewer approvals
- Security-sensitive changes: must include security review

## Decision Authority
- Architecture decisions: documented as ADRs in decision-log.md
- Daily operations: project lead approval
- Emergency fixes: post-hoc review within 48 hours
