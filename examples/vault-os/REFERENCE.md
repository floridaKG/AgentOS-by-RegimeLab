# Vault OS Reference

## Core Paths

| Path | Purpose |
|---|---|
| `capture/` | Incoming material |
| `sources/` | Source records and provenance |
| `insights/` | Atomic notes |
| `maps/` | Topic indexes and synthesis |
| `ops/` | Maintenance and workflow records |
| `registry/` | User-owned skill and workflow metadata |

## Linking

Vault OS uses standard Markdown and supports Obsidian-style `[[wikilinks]]`.

## Extension Boundary

Agent OS supplies the scaffold. Domain skills are separate installable
extensions and are not included in the open-source core.
