# Knowledge Lifecycle

1. Capture raw material in `capture/`.
2. Record provenance in `sources/`.
3. Extract small, reusable notes into `insights/`.
4. Connect insights through links and topic maps.
5. Validate required metadata and broken links.
6. Review stale, duplicated, or unsupported notes.

Automations should preserve user content and report proposed destructive
changes instead of applying them silently.
